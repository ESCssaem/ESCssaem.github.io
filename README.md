# ESC쌤의 수업 앱

ESC쌤이 만든 수업 앱 모음입니다. 첫 화면에서 **XR 수업 앱**(웹 XR·Quest 앱)과 **웹 수업 앱**(브라우저 활동 앱)을 나눠 보여 줍니다.

- 사이트: https://escssaem.github.io/
- 이 저장소에는 배포용 결과물과 소개 페이지만 있습니다. 앱은 수업에 자유롭게 활용할 수 있으며, 복제·수정 배포는 허락하지 않습니다.
- 목록: `apps.json`의 폴더 이름 순서. 각 폴더의 `app.json`에서 `category`(`xr`/`web`, 없으면 `xr`)로 구역을 정하고, `kind`가 `link`이면 다른 주소에서 운영하는 웹앱(카드의 '바로 사용하기'는 `url`로 연결)입니다.

## 교과목 수업 자료
- `ig2/` 통합과학2 수업 자료: 수업 슬라이드를 접속 코드로 암호화해 올린 것(`d/*.bin`). 첫 화면 '교과목 수업 자료' 구역(`category: lesson`)에 나온다. 빌드 도구와 코드는 이 저장소 밖(`통합과학&과학탐구실험/local-work/통합과학2_수업자료_사이트`)에 있다.
